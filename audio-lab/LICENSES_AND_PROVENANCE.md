# Licences and provenance

- This prototype ships no third-party JavaScript or Python packages, model weights, music recordings, album artwork or API client libraries.
- Its browser audio processing code is written for this prototype using standard Web Audio APIs and a small in-page FFT implementation.
- The mock catalogue is derived from the user's existing Sonic Companion MIE 1.3 fixture source supplied in this conversation/library. It contains the ten existing album/work families, track labels and authored listening-guide fixture text.
- No MOSS-Music weights or other pretrained audio models are included. The MOSS adapter contract is a specification only.
- No Spotify API is called, and no Spotify audio or metadata is processed.
- The prototype is not a licence grant for any recording. Users must only analyse recordings they are authorised to process. Rights in each sound recording and underlying composition must be checked separately.
