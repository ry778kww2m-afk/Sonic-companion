Check guide availability

This prototype uses a limited offline curated catalogue and optional Audio Lab measurements. It does not perform live web research. Unknown tracks remain without an editorial guide; measured signal changes are shown separately and never interpreted as instruments or musical events.

No live research service is configured in this build. Demo fixtures are not used by normal Spotify playback or guide lookup.

Offline musical translation

English remains the single canonical source. Brazilian Portuguese is resolved from a curated, deduplicated translation memory stored as a static app asset. No AI model or translation API is called. Text without an approved entry remains in English rather than receiving a literal or unreliable translation.
